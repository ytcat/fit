## Findings and changes

- Heavy uppercuts applied two arbitrary angular velocity kicks after the
  effective-mass collision. Removed those kicks. Rising friction now contributes
  a bounded impulse through the real contact lever arm and bag inertia.
- Dummy impacts applied an additional synthetic uppercut torque. Removed it;
  torque now derives from contact point and force about the captive stand joint.
  Damping and angular range give the torso a controlled recoil and settling motion.
- Uppercut target wrists could exceed arm reach as the bag moved. Bound wrist
  targets to the live shoulder's reachable sphere. Reduced lateral body sway and
  excessive recipient head/trunk extension. Earlier endpoint release prevents
  uppercuts lingering against the bag on recovery.
- Hook wrist calculation mutated the shoulder before setting height, effectively
  adding the height offset twice. Compute the target from a shoulder clone.
- Dummy: finer joined facial surface, molded brow/eyes, textured material, waist
  cuff and embossed target marks. Referee: fabric bump detail, pocket stitching,
  buttons and badge. These remain procedural models; parity with the lion is a
  visual goal, not an established quality measurement.
- Ring: flush canvas surface, four ropes, corner protection and red/blue corners.
  Dispose transient ring materials on mode changes while preserving shared ones.
- CPU canvas mocks returned no pixel data after the texture implementation changed;
  restored typed pixel buffers. Updated stale referee test API references and
  the hard-coded historical script-version assertion. Browser automation requires
  a test-context CSP bypass; the application's security policy remains unchanged.
