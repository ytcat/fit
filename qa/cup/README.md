# Local cup acceptance

Start the repository on http://127.0.0.1:8133, or set APP_URL. Browser scripts use the production app and M0 QA instrumentation to pause the automatic render loop, then explicitly drive the existing input/contact paths. Playwright is a development tool, not a game dependency.

- browser.cjs: entry and all nine localized layouts, a real production Play bout, saved checkpoint, fresh punch controls, one-shot descriptor and normal legacy Fight entry.
- playthrough.cjs: fixed cup seed74, ordinary commands against unchanged NPCs, no health/result manipulation. Three wins required six actual simulated bouts. Results include canonical records, title proofs and standard-only ledger transactions. These are scripted tests, not human activity claims.
- title-layout.cjs: replays captured actual records through CareerStore in a separate fixture for all nine completed-title layouts. Set PLAYTHROUGH_RESULTS to playthrough-results.json for a fresh machine; its default is the managed workspace output from playthrough.cjs. It does not claim a second set of played matches.

Reports and PNGs are actual app output. Archived title details may deliberately scroll when expanded; primary entry/title actions fit without scrolling. Physical Safari/Android FPS and thermal behavior remain unverified. See docs/game/F009-local-school-cup.md for source contract, gates and rollback.
